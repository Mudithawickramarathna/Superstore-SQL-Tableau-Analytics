# Superstore SQL & Tableau Analytics

##  Project Overview

This project analyzes the **Sample Superstore** dataset using **SQL and Tableau** to identify patterns in sales, profitability, discounts, customers, products, and regional performance.

The project demonstrates practical skills in **data analysis, SQL querying, data visualization, dashboard development, and business insights**.

## 🛠️ Tools & Technologies

* **SQL / MySQL** — Data querying and analysis
* **Tableau** — Interactive dashboards and visualization
* **Excel** — Initial data handling
* **GitHub** — Project documentation and portfolio

##  Dashboards

### 1. Sales Performance

* Sales performance overview
* Sales trends
* Category analysis
* Regional performance

### 2. Profit & Discount Analysis

* Total Profit KPI
* Profit by Category
* Profit by Region
* Discount vs Profit
* Category × Region Profitability

### 3. Customer & Product Analysis

* Total Customers KPI
* Sales by Customer Segment
* Top 10 Products by Sales
* Customer Sales vs Profit
* Category × Sub-Category Sales

##  Key Analysis Areas

* Sales and profit performance
* Regional profitability
* Discount impact on profit
* Customer segment performance
* Top-performing products
* Category and sub-category performance
